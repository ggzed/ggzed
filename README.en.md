# YF

#### Description
这是一个企业级后台管理系统，使用SpringBoot 3、Java 17、Vue 3和TypeScript开发。项目包含完善的权限系统、支持多种登录方式、限流、防重复提交等功能模块。集成NSFW过滤和SpringAi，确保内容安全与智能化体验。系统采用多种设计模式，支持企业级扩展和定制。欢迎各位提出宝贵意见，共同完善系统。
